🔍 敬語クイック早引き検索

了解しました / 了解です
承知いたしました / かしこまりました
「了解」には相手への敬意が含まれません。上司や取引先からの依頼・連絡には「承知いたしました」を使います。
ご苦労様です
お疲れ様です
「ご苦労様」は目上から目下にねぎらいをかける言葉です。目上の人には必ず「お疲れ様です」と言います。
すいません / すみません
申し訳ございません / 恐れ入ります
ビジネスシーンでの口頭やメールでは、「すみません」ではなく「大変申し訳ございません」が鉄則です。
拝見させていただきます
拝見いたします / 拝見します
「拝見する（謙譲語）」に「〜させていただく（謙譲語）」を重ねた二重敬語です。「拝見いたします」で十分な敬意が伝わります。
〇〇部長がおっしゃられました
〇〇部長がおっしゃいました
「おっしゃる（尊敬語）」に「〜られる（尊敬助動詞）」を重ねた二重敬語です。「おっしゃいました」が正しい形です。
なるほどですね / なるほど
おっしゃる通りです / おっしゃる通りでございます
「なるほど」は相手を評価・品定めするニュアンスを含むため、上司やお客様に対して使うのは大変失礼です。
書類のほうをお送りします
書類をお送りいたします
方向を指す言葉ではないものに「〜のほう」をつけるのは不自然なバイト敬語です。「書類をお送りいたします」とシンプルに表現します。
1,000円からお預かりします
1,000円をお預かりいたします
お釣りがある場合でも「〜から」をつけるのは誤りです。「〜をお預かりいたします」が正確な日本語です。

2. 「了解しました」「ご苦労様です」の間違いと正しい言い換え

日常生活で馴染みがある言葉ほど、ビジネスの現場では重大なマナー違反になるリスクを孕んでいます。

使ってはいけない表現 正しい言い換え 理由と注意点
了解しました 承知いたしました
かしこまりました		 「了解」は同僚や目下に「事情を分かった」と認めるニュアンスがあり、敬意がありません。
ご苦労様です お疲れ様です 「ご苦労様」は目上の者が目下をねぎらう言葉です。目上の人に使うと無礼になります。
参考になりました 勉強になりました
大変参考になりました（※注意）		 「参考」は自分の考えの足しにする程度という意味が含まれるため、「勉強になりました」が最も無難です。

3. 「おっしゃられた」「拝見させていただきます」二重敬語

敬語を重ねすぎると「慇懃無礼（丁寧すぎてかえって失礼・不自然）」になってしまいます。同じ種類の敬語（尊敬語＋尊敬語、謙譲語＋謙譲語）を重ねないのが基本ルールです。

  • ❌ ご覧になられる ➔ ⭕ ご覧になる（「ご覧になる」自体が尊敬語のため「〜られる」は不要）
  • ❌ 伺わせていただきます ➔ ⭕ 伺います / お伺いします
  • ❌ お召し上がりになられる ➔ ⭕ お召し上がりになる

4. お願い・お断りを角立てない「クッション言葉」一覧

本題の前に一言添えるだけで、依頼やお断りの印象が劇的に柔らかくなります。

場面 クッション言葉の定型フレーズ 実践例文
依頼・お願いする時 ・お忙しいところ恐縮ですが
・ご多忙中とは存じますが
・差し支えなければ 		「お忙しいところ恐縮ですが、明日までにご確認いただけますでしょうか」
お断りする時 ・大変心苦しいのですが
・あいにくではございますが
・ご期待に沿えず恐縮ですが 		「大変心苦しいのですが、今回は見送らせていただく運びとなりました」
確認・質問する時 ・失礼とは存じますが
・念のため確認させていただきたいのですが 		「失礼とは存じますが、お名前をもう一度伺ってもよろしいでしょうか」

5. ビジネスで誠意が伝わる「お詫び」の言葉遣い

「すみません」「ごめんなさい」はビジネスの謝罪では厳禁です。事態の重さに応じて適切な言葉を使い分けましょう。

謝罪のレベル別フレーズ
1. 日常の軽いお詫び: 「失礼いたしました」「恐れ入ります」
2. 一般的な謝罪: 「申し訳ございません」「深くお詫び申し上げます」
3. 重大なミス・会社としての謝罪: 「大変申し訳ございません」「弁解の余地もございません」「重ねて深くお詫び申し上げます」

6. 社内と社外での敬称ルール（「社長の〇〇」と呼ぶ理由）

社外の人に対して自分の上司や社長のことを話す際、「〇〇社長様」「〇〇部長」と呼ぶのはNGです。

  • 社外に対して: 自社の人間には敬称をつけず、役職名を後につけて「社長の〇〇は席を外しております」「部長の佐藤は外出しております」、または単に「佐藤は〜」と呼び捨てにします。
  • 社内に対して: 「佐藤部長」「社長」と呼び、「佐藤社長様」のように役職に「様」を重ねるのは二重敬称で誤りです。
