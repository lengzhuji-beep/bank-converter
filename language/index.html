🗣️ 敬語・言葉遣い早引き辞典

うっかり使ってしまいがちなNG表現と、相手に好印象を与える正しい敬語・クッション言葉をまとめました。

了解しました / 了解です
承知いたしました / かしこまりました
「了解」には敬意が含まれません。上司や取引先からの依頼・連絡には「承知いたしました」を使います。
ご苦労様です
お疲れ様です
「ご苦労様」は目上から目下にねぎらいをかける言葉です。目上の人には必ず「お疲れ様です」と言います。
すいません / すみません
申し訳ございません / 恐れ入ります
ビジネスシーンでの口頭やメールでは、「すみません」ではなく「大変申し訳ございません」が鉄則です。
拝見させていただきます
拝見いたします / 拝見します
「拝見する（謙譲語）」に「〜させていただく（謙譲語）」を重ねた二重敬語です。「拝見いたします」で十分な敬意が伝わります。
〇〇部長がおっしゃられました
〇〇部長がおっしゃいました
「おっしゃる（尊敬語）」に「〜られる（尊敬助動詞）」を重ねた二重敬語です。「おっしゃいました」が正しい形です。
なるほどですね / なるほど
おっしゃる通りです / おっしゃる通りでございます
「なるほど」は相手を評価・品定めするニュアンスを含むため、上司やお客様に対して使うのは大変失礼です。
書類のほうをお送りします
書類をお送りいたします
方向を指す言葉ではないものに「〜のほう」をつけるのは不自然なバイト敬語です。「書類をお送りいたします」とシンプルに表現します。
1,000円からお預かりします
1,000円をお預かりいたします
お釣りがある場合でも「〜から」をつけるのは誤りです。「〜をお預かりいたします」が正確な日本語です。

メールや会話が劇的に柔らかくなる「クッション言葉」一覧

相手に依頼や催促、お断りをする前に添えるだけで、トーンが柔らかく丁寧になる魔法のフレーズです。

場面 使えるクッション言葉 文例
何かを依頼する時 ・お忙しいところ恐縮ですが
・ご多忙中とは存じますが
・差し支えなければ 		「お忙しいところ恐縮ですが、明日までにご確認いただけますでしょうか」
お断りをする時 ・大変心苦しいのですが
・あいにくではございますが
・ご期待に沿えず恐縮ですが 		「大変心苦しいのですが、今回は見送らせていただく運びとなりました」
尋ねる・確認する時 ・差し支えなければ
・失礼とは存じますが
・念のため確認させていただきたいのですが 		「失礼とは存じますが、お名前をもう一度伺ってもよろしいでしょうか」
